# p10. 서울시의회형 빅데이터 분석 — 2026년도 예산안 쟁점

> 소관: 의회사무처 재정분석과 · 운영위원회 · 일반회계 · 계속·경상
> 원문: 운영위 예비심사보고서 p.67~68(검토보고) · 사업설명서 p.199~202 · 의회 조정: **전액 감액 △129.607**
> 단위: 원문 천원, 본문 백만원 · 외부 근거는 검색 요약 기준

## 사업 요약 카드

```
[사업] 서울시의회형 빅데이터 분석 | 2025 60 → 2026안 129.607 (+116%) | 의회 조정: 전액 감액(△129.607) → 0

── 핵심 쟁점 ──
쟁점 1. 사업 방향이 정해지지 않은 채 단가만 2배 — 회당 495만원 → 1,000만원 × 11회, 근거는 "보편적 시장 단가" 한 줄
 · 질의: "회당 1,000만원이 '보편적 시장 단가'라는 근거로 비교한 업체 견적이나 유사 용역 계약 사례를 말씀해 주십시오."
 · 조정: 의회 전액 감액 유지(방향·단가 근거 미비)
쟁점 2. 2025년 분석 주제(강사료·사례금 분석, 입지 분석 등)는 "빅데이터"가 아닌 행정자료 분석 — 사업명·목적과 실제 과업이 다름
 · 질의: "2025년 보고서 7건 중 온라인·대용량 데이터를 실제로 쓴 보고서는 몇 건이고, 각각 어떤 데이터를 몇 건 분석했는지 말씀해 주십시오."
 · 조정: 재편성 시 과업 범위 명확화 조건
쟁점 3. 계약을 먼저 하고(1~2월) 분석 과제는 나중에 수요조사(2~3월) — 과업이 정해지지 않은 용역을 제한경쟁으로 일괄 발주
 · 질의: "과제가 정해지지 않은 상태에서 제한경쟁입찰 과업지시서에는 무엇을 적을 계획이었는지 말씀해 주십시오."
 · 조정: 재편성 시 과제 확정 후 발주 조건

── 추가 쟁점 ──
쟁점 4. 2024년 시범 주제(교육감 선거, 도심 집회, 파업 등) — 의회사무처의 온라인 여론 모니터링은 정치적 중립성·개인정보 기준이 필요
쟁점 5. 재정분석과 자체 분석 기능, 서울시 본청 데이터 플랫폼(데이터 허브·민원분석 시스템)과의 중복 — 외주 필요성
쟁점 6. 성과지표가 없음 — 보고서 활용(질의·조례·예산심사 반영) 실적을 재는 지표가 필요

외부 이슈: [서울시] 2건 · [회의록] 0건(사이트 접속 차단) · 이 사업을 다룬 언론 보도는 검색되지 않음
종합 조정 의견: 의회 전액 감액 유지. 재편성(추경·2027 본예산) 시 조건 3가지 — 사업 방향 확정, 단가 근거 제시, 과제 확정 후 발주
```

## 핵심 쟁점

### 쟁점 1. 사업 방향 미정 상태에서 단가만 2배 — "보편적 시장 단가" 근거 없음
`종류: 산출근거 부실·단가 과다` · `결론: 감액 검토 필요` · `중요도: 꼭 들어가야 함` · `출처: 전문위원 검토의견, 의회 감액(조정)과 관련`

■ 현황
- 2026년안: 보고서 회당 10,000천원 × 11회 = 110,000 + 데이터 구매 6,000천원 × 3회 = 18,000 + 제안서 평가위원회 200천원 × 8명 = 1,600 → 사무관리비 129,600; 문자 전송료 4.2원 × 150건 × 11회 = 6.93천원 → 7 (재계산 일치) [설명서 p.200]
- 증감사유: "심화 기획분석 회당 단가 상향조정(495만원 → 1,000만원, 보편적 시장 단가 적용)" [설명서 p.200] → +102%(재계산)
- 전문위원: "사업의 성격과 목적이 충분히 정립되지 않은 상태에서 비용 구조만 먼저 확대되는 결과를 초래할 우려", "① 의회 공동 활용을 위한 상시 여론·정책 모니터링 인프라 구축 사업으로 추진할 것인지, ② 개별 의원 또는 상임위원회 수요에 대응하는 맞춤형 정책분석 서비스 사업으로 운영할 것인지 명확한 사업 방향을 설정할 필요" [검토 p.68]
- 의회 조정: 사무관리비 128,000 + 1,600, 공공운영비 7 전액 감액(합계 △129,607) [의회 조정내역]

■ 문제점
- 단가를 2배로 올린 근거가 "보편적 시장 단가" 한 줄뿐임. 비교 견적·유사 계약 사례가 없음.
- 사업 방향(상시 모니터링 인프라 / 맞춤형 분석)이 정해지지 않아 회당 단가의 적정성도 판단할 수 없음.

■ 의원 질의문
1. "사무처장님, 분석 보고서 1건 단가를 495만원에서 1,000만원으로 올리면서 '보편적 시장 단가'라고 하셨습니다. 비교한 업체 견적이나 유사 용역 계약 사례가 몇 건이고 평균 단가가 얼마였는지 말씀해 주십시오."
   - 재질의: "2025년에 495만원으로 만든 보고서와 2026년 1,000만원짜리 보고서는 분석 범위나 데이터 양에서 무엇이 달라지는지 구체적으로 말씀해 주십시오."

■ 요구자료
- 단가 산정 근거(견적서·유사 계약), 2025년 보고서별 계약 금액과 투입 인력

■ 조정 의견
- **의회 전액 감액(△129.607) 유지.** 재편성 조건: ① 사업 방향(인프라형/맞춤형) 확정 ② 단가 산정 근거 제출 ③ 과제 확정 후 발주(쟁점 3).

### 쟁점 2. 2025년 분석 주제는 "빅데이터"가 아닌 행정자료 분석 — 사업명과 실제 과업 불일치
`종류: 사업 필요성·효과 불분명` · `결론: 사업 재검토·보류` · `중요도: 꼭 들어가야 함` · `출처: 전문위원 검토의견`

■ 현황
- 2025년 산출근거는 "온라인 주간 이슈 보고서 작성 60,000,000원" [설명서 p.200]
- 실제 2025년 주제 7건: 유보통합 시민 인식, 공공체육시설 입지(영등포구), 보건복지위 소관 기관 외부강의 강사료 분석, 어린이보호구역 속도제한 시민 인식, 종로구 소규모주택정비 수요 예측, 자치구별 도심복합개발 가능지역, 보건복지위 소관 기관 종사자 외부활동 사례금 분석 [검토 p.68 각주 44; 설명서 p.202]
- 전문위원: "빅데이터 분석 주제인지 일반적인 데이터 분석 주제인지 모호", 2025년부터 "행정자료 및 조사데이터를 활용한 정책기획·효과분석 중심으로 사업 방향이 전환되면서, 개별 의원 요구사항에 기반한 맞춤형 분석 사업으로 성격이 변화" [검토 p.67~68]

■ 문제점
- 예산은 "주간 이슈 보고서"(1년이면 약 52건)로 잡았는데 실제 결과물은 7건이고, 내용도 행정자료 분석임. 편성 목적과 집행 내용이 다름.
- 강사료·사례금 분석 같은 주제는 상임위원회 자료 요구로 받을 수 있는 자료라, 외부 용역이 필요한지 의문임.

■ 의원 질의문
1. "2025년 보고서 7건 가운데 온라인 커뮤니티나 대용량 데이터를 실제로 분석한 보고서는 몇 건이고, 각각 어떤 데이터를 몇 건 분석했는지 말씀해 주십시오."
2. "2025년 예산은 '주간 이슈 보고서'로 편성됐는데 결과물은 7건입니다. 6천만원으로 보고서 몇 건을 계약했고 건당 얼마였는지 말씀해 주십시오."

■ 요구자료
- 2025년 보고서 7건 원문과 사용 데이터 목록, 계약서(과업 범위·건수)

■ 조정 의견
- 사업 재검토. 사업명을 실제 과업(맞춤형 정책분석)에 맞게 바꾸거나, 빅데이터 인프라 사업으로 다시 설계할 것.

### 쟁점 3. 계약 먼저(1~2월), 과제 수요조사는 나중(2~3월) — 과업 불특정 용역
`종류: 위탁·보조 방식·계약` · `결론: 집행 관리·계획 보완 요구` · `중요도: 꼭 들어가야 함` · `출처: 분석관 판단으로 추가`

■ 현황 (설명서 p.201 2026년도 추진일정)
- 사업계획 수립 2025.12~2026.01 → **전문업체 선정 및 계약 2026.01~02(129,600, 제한경쟁입찰)** → **수요조사 2026.02~03(빅데이터 분석 과제 수요조사)** → 분석 2026.03~12(보고서 11건)

■ 문제점
- 분석 과제를 정하기 전에 업체를 고르면, 과업지시서에 무엇을 분석할지 적을 수 없고 제안서 평가 기준도 모호해짐. 결국 한 업체가 성격이 전혀 다른 11개 주제(교육·보건·도시계획 등)를 맡는 구조가 됨.
- 데이터 구매(6백만원 × 3회)도 과제를 모르는 상태에서 횟수를 정함.

■ 의원 질의문
1. "과제가 정해지지 않은 상태에서 제한경쟁입찰 과업지시서에는 분석 대상과 데이터를 어떻게 적을 계획이었는지, 2025년 과업지시서는 어떻게 적었는지 말씀해 주십시오."
2. "데이터 구매를 3회로 정한 근거와, 2025년에 실제로 구매한 데이터와 금액을 말씀해 주십시오."

■ 요구자료
- 2025년 과업지시서·제안요청서, 데이터 구매 내역

■ 조정 의견
- 재편성 시 부대의견(안): "분석 과제를 먼저 확정한 뒤 과제별 또는 분야별로 발주할 것."

## 추가 쟁점

### 쟁점 4. 2024년 시범 주제(교육감 선거·도심 집회·파업 등) — 정치적 중립성·개인정보 기준 필요
`종류: 기타(정치적 중립성·개인정보)` · `결론: 집행 관리·계획 보완 요구` · `중요도: 들어가면 좋음` · `출처: 분석관 판단으로 추가`

- 2024년 "온라인 커뮤니티 빅데이터를 활용한 디지털 분석 시범사업" 10회: 한강 불꽃축제, **서울교육감 선거**, 버스 준공영제 개편, **서울 도심 집회**, 그린벨트 해제, 도심항공 실증, **지하철 태업·파업**, 폭설, **교육공무직 파업**, 철도 지하화 [설명서 p.202]
- 의회사무처는 의원 전체를 지원하는 조직이라, 선거·집회·파업처럼 정치적으로 민감한 주제의 온라인 여론을 모니터링할 때는 주제 선정 기준과 결과 공개 범위가 있어야 함. 온라인 커뮤니티 게시글 수집 시 개인정보 처리 기준도 원문에 없음.
- 질의: "2024년 시범사업의 주제는 누가 어떤 기준으로 정했는지, 결과 보고서는 어느 범위에 공개했는지, 게시글 수집 때 개인정보 처리 기준이 무엇이었는지 말씀해 주십시오."

### 쟁점 5. 재정분석과 자체 기능·서울시 본청 데이터 플랫폼과의 중복
`종류: 유사·중복 사업` · `결론: 자료 보완·제출 요구` · `중요도: 들어가면 좋음` · `출처: 분석관 판단으로 추가`

- 사업수행 주체는 재정분석과이고 [설명서 p.201], 사업근거에 "의정활동 지원 시스템 구축 계획(예산정책담당관-2532, 2021.9.30.)" 등 사무처 내부 계획이 있음 [설명서 p.201]
- [서울시] 서울시 본청은 직원의 데이터 분석을 지원하는 AI 기반 플랫폼과 "서울 데이터 허브"를 단계적으로 구축했고, 2020년에는 일평균 7,000여 건의 민원을 실시간 분석하는 응답소 민원분석 시스템을 구축함(행정분야 누리집, 검색 요약 기준)
- 질의: "같은 분석을 재정분석과 직원이 서울시 데이터 허브나 민원분석 시스템을 써서 할 수 없는 이유와, 외주로 했을 때 얻는 것이 무엇인지 말씀해 주십시오."

### 쟁점 6. 성과지표 없음 — 보고서 활용 실적을 재는 지표 필요
`종류: 성과지표·성과관리` · `결론: 자료 보완·제출 요구` · `중요도: 들어가면 좋음` · `출처: 분석관 판단으로 추가`

- 달성목표는 "시민 생활에 밀접한 이슈와 관련 온라인 여론 동향을 분석하여 정책제안을 제시할 기초·참고자료 제공" 서술뿐 [설명서 p.202]
- 보고서가 의원 질의, 조례 발의, 예산 심사에 몇 번 쓰였는지를 재는 지표가 없음
- 질의: "2024~2025년 보고서 17건이 상임위 질의, 조례안, 예산 심사에 실제로 활용된 건수를 말씀해 주십시오."
- 조정 의견: 재편성 시 활용 실적 지표 설정 조건.
