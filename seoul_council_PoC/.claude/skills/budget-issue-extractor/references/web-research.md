# 회의록(속기록)·웹 이슈 조사 방법

## 1. 무엇을 찾나
| 찾는 것 | 쟁점으로 쓰는 법 |
|---|---|
| 전년도 본예산·추경 심사 때 같은 사업에 대한 의원 지적 | "작년에 지적됐는데 올해도 같음" → 반복 지적 쟁점 |
| 결산·행정사무감사 지적과 시정 요구 | 시정 요구 이행 여부를 질의 |
| 상임위·예결위 부대의견 | 이행 여부 확인 |
| 언론 보도(효과 논란, 사고, 민원, 특혜 의혹, 집행 부진) | 외부 이슈 쟁점, 현장 근거 |
| 감사위원회·감사원 감사결과, 지방재정 공시 | 위법·부당 처분, 재정지표 |
| 다른 지자체·중앙정부 유사사업 | 중복 쟁점, 비교 단가 |

## 2. 검색어 패턴
사업명은 원문 표기 그대로 쓰고, 줄임말·옛 사업명도 함께 검색한다.
- `"사업명" 서울시의회`
- `"사업명" 예산 삭감` / `"사업명" 감액`
- `"사업명" 행정사무감사` / `"사업명" 결산`
- `"사업명" 추경`
- `"소관 부서명" "사업명" 문제` / `논란`
- `"사업명" 감사위원회` / `"사업명" 감사원`
- 의원 발언을 찾을 때: `"사업명" 의원 지적`, `"사업명" 시의원`

연도를 넣어 최근 2~3년(전년도 본예산, 당해 추경, 전년도 결산, 행정사무감사)으로 좁힌다.

## 3. 출처 등급과 표기
| 등급 | 표기 | 예 | 사용 |
|---|---|---|---|
| 1 | `[회의록]` | 서울시의회 회의록 원문 (council.seoul.go.kr), 지방의회 회의록 통합검색 (clik.nanet.go.kr) | 발언 직접 인용 가능 |
| 2 | `[의회보도]` | 시의회·위원회·교섭단체 보도자료 | 지적 내용 인용 |
| 3 | `[언론]` | 일간지·통신사·지역 언론 기사 | 사실 보도 인용. 기사 속 발언은 "회의록 원문 대조 전" 표시 |
| 4 | `[감사·공시]` | 감사결과 공개문, 지방재정365, 기관 공시 | 처분·지표 인용 |
| - | 쓰지 않음 | 블로그, 카페, 커뮤니티, 출처 불명 요약 | 단서로만 쓰고 원출처를 다시 찾는다 |

## 4. 인용 형식
- 회의록: `[회의록] 제○○○회 ○○위원회 제○차 (2025.11.○.) ○○○ 의원 — "발언 요지"`
- 언론: `[언론] ○○일보 2026.9.11. "기사 제목" — 요지 (URL)`
- 의회보도: `[의회보도] ○○위원회 보도자료 2026.○.○. — 요지 (URL)`

일자, 출처, URL이 모두 있어야 근거로 쓴다. 하나라도 빠지면 `[확인 필요]`를 붙인다.

## 5. 주의
- 검색 결과 요약문만 보고 쓰지 말고, 가능하면 원문을 열어 확인한다. 열 수 없으면 "검색 요약 기준"이라고 밝힌다.
- 같은 이름의 다른 사업(다른 지자체, 다른 연도)을 섞지 않는다. 지자체명·연도·부서가 맞는지 확인한다.
- 정치적 공방 기사(정당 논평)는 사실 근거가 아니라 쟁점이 있다는 신호로만 쓴다. 수치는 원자료로 확인한다.
- 회의록 사이트가 막혀 있으면 사용자에게 도메인 허용(`council.seoul.go.kr`, `clik.nanet.go.kr`)을 요청하거나, 가진 회의록 파일을 받는다.
