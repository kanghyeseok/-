```

 · 질의: <가장 중요한 질의 1개>
 · 조정: <감액 ○○백만원 / 부대의견 / 원안>
쟁점 2. ...
쟁점 3. ...

종합 조정 의견: 감액 ○○백만원 (검토보고·조정안 대비: 동일 / 추가 ○○ / 축소 ○○)
```

## 쟁점 상세 (쟁점마다 반복)

```
### 쟁점 N. <쟁점 제목 — 결론형 한 문장>
체크리스트: ③ 집행 가능성, ⑤ 증액 사유

■ 현황 (핵심 수치 3개 이내)
 - 2027 요구액 ○○백만원(전년 대비 +○○%)  [사업설명서 p.○]
 - 2025 집행률 ○○% (예산현액 ○○ / 집행 ○○)  [검토보고 p.○]
 - ...

■ 문제점
 - 2~3문장. 법령·조례·편성기준 조문을 구체적으로.

■ 근거
 - 검토보고 p.○: "<원문 인용>"
 - 조정안: <반영 여부와 금액>
 - 회의록: 제○회 ○○위원회 (20○○.○.○.) ○○○ 의원 – "<발언 요지>"  (확인 못 하면 생략)

■ 의원 질의문
 1. "<실국장이 숫자·일정으로 답하게 하는 질문>"
    - 예상 답변: ...
    - 재질의: "<답변이 부족할 때 이어 갈 질문>"
 2. ...

■ 요구자료
 - <구체적 자료명, 기간 범위>

■ 조정 의견
 - 감액 ○○백만원 = <산식, 예: 단가 ○○원 × 감축 수량 ○○개>
 - 또는 부대의견: "<문안>"
 - 조정안과 비교: 동일 / 추가 감액 / 의견 상이(사유)
```
