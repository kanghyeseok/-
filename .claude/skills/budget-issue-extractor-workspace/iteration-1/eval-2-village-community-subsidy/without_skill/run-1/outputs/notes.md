# notes (without_skill baseline)

## 사용 도구
- Bash + `python3 -I`: 입력 HTML 태그 제거 후 텍스트 추출(파일 6,044 bytes, 사업 1·2 포함; 사업 2만 분석)
- korean-law MCP
  - `search_law`: 지방자치단체 보조금 관리에 관한 법률(MST 249861), 시행령(MST 255155)
  - `get_law_text`: 법 제5조·제6조·제7조·제27조, 시행령 제3조·제4조·제16조
  - `execute_tool` → `search_ordinance` / `get_ordinance`: 서울특별시 지방보조금 관리 조례(ordinSeq 2070423) 제3조·제9조·제18조
- budget-issue-extractor 스킬 미사용(지시사항)

## 불확실성
- 「서울특별시 마을공동체 활성화 지원 조례(가상)」은 가상 조례라 원문 확인 불가. 운영비 보조 명시 조항 유무에 따라 A안(△400) 근거 강도가 달라짐.
- 법 제6조②의 "법령"에 조례가 포함되는지는 해석 논란이 있을 수 있어 보고서에서는 단정하지 않음.
- 예산과목 307-02(민간경상사업보조)와 운영비 과목 구분은 행안부 「지방자치단체 예산편성 운영기준」 원문을 조회하지 않았음(확인 필요로 표시).
- 사업 2 원문에 집행실적·2026년 세부 산출내역이 없어 집행률 기반 감액 논거는 쓸 수 없었음.
- 증액 200 vs 단체 5개 증가(5×20=100) 불일치는 사업설명서 수치만으로 도출한 추론임(2026년 단가가 다를 수 있음).
- 법령 조문은 2026.10.12. 기준 현행본(법 시행 2023.10.12., 시 조례 시행 2025.09.29.)으로 확인.
